# 验证范围

## 已执行

| 检查 | 方式 | 能支持的结论 |
| --- | --- | --- |
| 账号身份、来源、刷新保存、回滚、锁与调度握手 | 合成凭证与依赖注入单元测试 | 拒绝错误身份和待执行冲突；失败分支不冒充成功 |
| 聊天活动保护 | 原生 SQLite 合成数据库测试；本地状态只读核对 | 按每个线程的最新轮次判断；阻止其它活动、调用方新轮次与未结束轮次；坏库或未知结构停止 |
| Windows 进程结束 | 对测试自有进程执行精确句柄核验、终止与退出竞态测试 | 身份错配不终止；已退出目标不触发误回滚 |
| WMI 启动与隔离 | 真实 `LaunchWorker`，使用自有测试 Job Object | 同用户、同会话、正确目录与环境过滤；父作业终止后测试 worker 仍完成 |
| 完整脚本衔接 | 真实 WMI/握手/本地 SQLite/私密文件写入，合成凭证、模拟网络与桌面操作 | 三阶段握手、3 秒等待、关窗前复查、凭证保存、认证结果处理和清理可以衔接；不构成真实账号登录验证 |
| 技能与隐私 | 技能结构校验、发布文件扫描和独立逐文件语义审查 | 发布包不携带本机配置、真实凭证、运行快照或个人路径；扫描与语义审查共同执行 |

较早的 20 秒启动等待、15 秒正常退出等待版本，已完成真实 Windows 桌面 Pro → Plus → Pro 切换；重开后用原生额度工具核对了目标套餐。当前 3 秒/5 秒版本没有为了测试而再次切换真实账号，也未实测新的整流程耗时。

## 可重跑命令

在仓库根目录使用 Node.js 24+：

```powershell
node --test
powershell -NoProfile -NonInteractive -ExecutionPolicy Bypass -File tests/windows-smoke.ps1
node tests/pipeline-smoke.cjs
```

Windows 测试只管理自己创建的进程和系统临时目录，不调用真实桌面关闭、不读取登录凭证，不联系 OpenAI 或代理控制器。临时目录清理先验证路径边界。

## 必须保留的边界

- 活动信息来自本机持久化投影，不能证明远程/云端或另一台机器空闲；数据结构升级时会停止执行。
- 检查与退出不是整个应用的事务锁，用户在最后检查后仍可开始新任务。
- 后端认证和桌面启动通过后，仍需原生账号工具或头像菜单确认桌面身份。
- 文件保存成功与令牌刷新是两回事。只有实际令牌字段变化才记录变化；有效令牌不强制刷新。
- 3 秒和 5 秒分别是配置的启动宽限与正常退出宽限；网络、权限操作和认证另计。
